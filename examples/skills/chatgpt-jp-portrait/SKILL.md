## 两种摄影风格

- **J01 日系自然写实**：像相机拍摄的日常人像，柔和自然光、清爽配色、真实皮肤和布料纹理、自然成人面部与身体比例，适度修饰，不做塑料皮肤或夸张动漫五官。
- **J02 Coser 写实摄影**：真实成年 coser 的角色服装摄影，明确发型、假发或发饰、服装层次、道具材质和展会／影棚环境。人物与服装都应具有实拍质感；不要因为“coser”自动转成动漫插画或加入性暗示。

用户指定具体服装或角色时按其可见特征描述，不擅自增加暴露设计。参考图可分别用于发型、服装、姿势或风格；明确各图用途，不从图片臆断真实人物的年龄。

## 自定义动作解析

不强迫用户选择最接近的模板。直接从描述提取下列要素，并整理成一段可见、可执行的动作：

1. **姿态与支撑**：站、坐、行走或其他普通姿态；身体朝向、支撑物、重心。
2. **双手任务**：每只手的位置、接触对象、握持方式。避免一只手同时做两个动作。
3. **头部与视线**：头的朝向、看镜头／道具／远处，以及表情。
4. **动态瞬间**：抓拍动作中的哪一刻，发丝、衣物和道具是否随之运动。
5. **构图需求**：用户希望看清什么，哪些动作需要出现在画框中。

例如“走在街上，听见有人叫她，回头笑，左手拎包”可整理为：缓步行走中适度侧转上身并回头微笑看镜头，左手自然拎包，右手随步伐摆动；全身镜头保留落地的一步。

处理原则：

- 用户明确的动作与部位 > 模板默认动作 > 通用缺省值；保留所有兼容要求。
- “甜一点”“自然一点”落到微笑幅度、肩膀放松、手指姿态和配色，不变成年龄或身体尺度指令。
- 两个动作占用同一只手时，若用户未指定左右可合理分配；若明确要求同一只手同时完成互斥动作，提出一个简短澄清。
- “背对镜头但露出完整正脸”等要求，说明构图冲突并提供可行选项，不写无法实现的姿势。
- 特写只描述画面可见的动作和必要支撑；不再要求画外的脚、手或脸同时入镜。

## 组织最终提示词

用自然中文，按“人物与风格 → 服装场景 → 动作视线 → 裁切焦点 → 光线质感”的顺序组成一段。简单需求用3—5句即可；复杂动作才增加细节。保持要求相互一致，不堆叠无关词语。

基础句式：

> 生成一张日系写实摄影照片，主体是一位虚构的18岁成年女性，气质甜美可爱，具有自然成人比例与真实肤质。她穿着【服装】，位于【场景】，正在【可执行动作】，视线【方向】，表情【描述】。采用【景别及裁切边界】，焦点在【目标】，画幅【比例】。使用【光线】，保留自然肤色与布料细节，背景【处理】。

Coser 模式把开头换成“真实成年 coser 的角色服装摄影”，再补具体服装和道具材质。特写模式省去画框外的复杂场景和动作，不为了重复年龄而要求脸入镜。

镜头焦距、光圈或胶片感可以作为视觉方向；不承诺严格物理模拟或某个精确输出分辨率。不默认加入 API 参数、权重语法、采样器、种子或专属 negative prompt 字段。

输出方式：

- **直接出图**：必要时用一句话说明采用的动作与镜头，然后调用可用图像生成能力；不要为普通合规摄影重复输出说明。
- **只要提示词**：输出一个包含完整提示词的代码块。若为解决冲突而做了调整，在代码块外简述变化；无需附长篇分析。
- **选择模板**：给出简短菜单，用户选定后直接执行；记住当前会话已选的风格、服装与镜头。
- **连续改图**：使用上一张实际图片或用户参考图，明确“只改变什么”与“保持什么”。没有可访问参考图时先请用户提供；仅有文字无法保证同一张脸。

## 生成失败与后续修正

根据实际界面或工具返回区分情况，不猜测审查原因，不提供虚构的通过率。

- **内容拒绝**：说明收到内容限制。原意属于普通合规摄影且可通过实质澄清消除歧义时，保留用户目标，明确服装、动作和镜头的实际内容；最多再提交一次，并简述改动。若请求本身不符合规则，不把它改名、拆分或编码后继续提交，提供合规的摄影替代方向。
- **额度、登录或权限限制**：如实告知具体阻塞，保留最终提示词；不通过换词解决。
- **网络、超时或服务错误**：只有已确认上一请求失败、没有正在生成的任务时才最多重试一次；状态未知时先查看，不连续提交。
- **画面质量问题**：已经生成但动作、手部或裁切不理想属于改图问题；针对一个问题修改，保留人物、服装、光线和其他正确内容。
- **再次失败或原因不明**：停止自动尝试，说明可观察到的结果并交付提示词；不要把模糊错误归因为审查，也不要保证下一次成功。

除用户原请求外，自动再次提交总计最多一次；用户之后明确提出的新修改按新请求处理。只在确实有图片输出时报告出图成功；网页版是否成功以网页版实际返回为准。
